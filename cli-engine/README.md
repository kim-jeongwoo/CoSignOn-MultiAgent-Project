# cli-engine

AI 팀 채팅방 수정안 v2의 알고리즘을 테스트하는 실험용 엔진입니다.
Claude, GPT, Gemini가 정해진 순서 없이, 공유 폴더의 파일을 직접 읽고 토의합니다.

## 실행 조건
- Python 3 (표준 라이브러리만 사용)
- 아래 CLI 3개가 설치되어 있고 각자 구독 계정으로 로그인되어 있어야 함
  - Claude: `claude`
  - GPT: `codex`
  - Gemini: `agy`
- API 키는 사용하지 않음 (실행 시 API 키 환경변수를 지우고 구독으로 호출)

## 실행
python3 engine.py
→ 문제를 입력하면 시작합니다.

## 결과 파일
~/.chatroom_workdir/v2-날짜시각/ 폴더에 생깁니다.
- chat.md: 전체 대화
- summary.md: 세 AI가 모두 동의한 요약
- draft.md: 산출물
- log.jsonl: 호출 기록 (걸린 시간, PASS 여부, 재판단 결과)

## 알려진 문제
- Gemini 응답이 느림 (1~3분)
- Gemini 타임아웃이 300초에서 끊기지 않는 경우가 있음 (수정 예정)
- Gemini는 테스트용으로 모든 권한을 허용한 상태
- 사람 개입 기능(요약 3회 반대, 대립 시 사람 결정)은 아직 테스트하지 않음

자세한 알고리즘은 "AI 팀 채팅방 수정안 v2" 문서 참고 부탁드립니다.
